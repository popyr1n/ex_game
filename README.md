# PERQUE Fan Service Platformer

Мини-игра в стиле **Contra / Battletoads / Mario**: персонаж бегает, прыгает, уклоняется от врагов, подбирает оружие и стреляет.

## Что реализовано
- 3 уровня с ростом сложности.
- Разные типы оружия (`basic`, `burst`, `plasma`) через pickups.
- Враги-патрульные и финальный босс на 3-м уровне.
- Победный экран с промокодом на скидку для магазина бренда одежды **Perque (Санкт-Петербург)**.

## Управление
- `A/D` или `←/→` — движение
- `W` / `↑` / `Space` — прыжок
- `F` — выстрел
- `Enter` — старт игры
- `R` — перезапуск из экранов победы/поражения

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Структура
- `src/config.py` — константы, оружие, описание трёх уровней.
- `src/entities.py` — игрок, враги, босс, пули, пикапы.
- `src/levels.py` — сборка состояния уровня из конфигурации.
- `src/main.py` — игровой цикл, рендер и обработка состояний.
